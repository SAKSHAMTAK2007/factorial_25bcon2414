# Fibonacci Sequence Generator

A simple Python program that generates and displays the first 10 numbers of the Fibonacci sequence using an iterative approach.

## 📌 Project Description

This project demonstrates how to generate Fibonacci numbers in Python using a `for` loop. The program starts with `0` and `1` and calculates each subsequent number by adding the previous two numbers.

## ✨ Features

* Generates Fibonacci numbers.
* Uses a simple `for` loop.
* Easy-to-understand implementation.
* Requires no external libraries.

Run the program using:

```bash

```

The program currently generates the first **10 Fibonacci numbers**.

To generate a different number of terms, change the value of `n`:

```python

```
