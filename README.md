# Fibonacci Sequence Generator

A simple Python program that generates and displays the first 10 numbers of the Fibonacci sequence using an iterative approach.

## Project Description

This project demonstrates how to generate Fibonacci numbers using a `for` loop. The program starts with `0` and `1`, then calculates each subsequent number by adding the previous two numbers.

## Features

* Generates Fibonacci numbers.
* Uses a `for` loop.
* Simple and easy-to-understand implementation.
* Requires no external libraries.
